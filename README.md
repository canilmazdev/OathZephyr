## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/OathZephyr.git`
2. `cd OathZephyr`
3. Install in editable mode: `pip install -e .`

## Configuration

OathZephyr is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
